# 共享量化方法库登记册（Method Library Registry）

> **定位**：为本对话全部策略（选品扫描 S-004 及因子框架 RS001、择时 S-001/002/003）
> 提供**基本量化工具的单一事实来源**（single source of truth）。
> 每个方法一处定义，多方消费；扫描层与择时层禁止各自私改判据。
>
> **登记原则**：
> 1. 每个方法有永久 ID（`M-类别-序号`）、唯一权威定义（本登记册对应小节）
> 2. 消费方（策略/因子）只引用 ID，不复制定义
> 3. 定义变更走修订记录，并通知全部消费方（记录在"消费方"列）
> 4. 现网已实现的方法标注代码位置；未实现的标注状态

## 方法分类

| 类别代码 | 类别 | 说明 |
|----------|------|------|
| KB | K线组合（K-combination） | 单根/多根 K 线形态判据 |
| EX | 动能衰竭（Exhaustion） | 推动结构衰减、动能量化 |
| DV | 量价背离（Divergence） | 量能 vs 价格背离 |
| FL | 失败形态（Failure） | 突破失败、反转失败 |
| PT | 形态结构（Pattern） | 摆动点、双顶底、楔形等结构判据 |
| TR | 趋势度量（Trend） | 方向、强度、效率 |
| LV | 关键位（Levels） | 支撑压力、区间边缘 |
| VR | 波动率/量能基础（Volatility/Volume） | ATR、量能归一化等底层量 |

## VR 波动率/量能基础

### M-VR-001 ATR（Average True Range）
- **定义**：周期 14 的真实波幅均值，全库统一归一化基准
- **状态**：✅ 已实现（`vnpy_patiming/config.py::atr_period`，引擎结构层）
- **消费方**：几乎所有方法

### M-VR-002 量能归一化
- **定义 v1（QA 定稿草案，2026-10-12）**：
  1. 相对量 `rvol_t = volume_t / ts_mean(volume, n)`，基准窗口 n=20（60m 根）
  2. **换月处理**：复权拼接标记根及其后 1 根的 volume 置 NaN（换月量失真，不插值）
  3. **时段修正**：夜盘/日盘成交量密度不同，rvol 按"同时段历史均值"再归一：`rvol_adj = rvol / seg_mean_rvol`，seg ∈ {日盘, 夜盘}（修正系数用滚动 60 根估计）
  4. 极端值截断：rvol_adj 在 [0, 10] 之外截断
- **消费方**：M-DV-001/002、M-EX-003
- **状态**：🟡 定义定稿待评审；研究级代码已实现（code/methods，v1 无时段修正版 + 预留接口）

## TR 趋势度量

### M-TR-001 EMA 方向（定性）
- **定义**：EMA20 斜率 >0 / <0

- **消费方**：S-002 全部、context_tag

### M-TR-002 趋势强度分值（trend_score）
- **定义 v1**（RES+QA 定稿草案，2026-10-12）：
  方向 dir = sign(EMA 斜率)；强度 score ∈ [0,100] = 加权和：
  | 分量 | 归一化 | 权重 |
  |------|--------|------|
  | EMA 斜率强度 | tanh(|EMA20−EMA20[5]| / ATR / 2) | 0.30 |
  | 摆动点递进合规率 | 最近 4 个摆动点满足 HH/HL（或 LL/LH）序列的比例 | 0.25 |
  | 趋势效率 | |净位移| / Σ|单根位移|（近 20 根，Kaufman ER） | 0.25 |
  | 趋势年龄 | exp(−age/(3×atr_period))，越新越高 | 0.10 |
  | 多周期一致性 | 大小周期 dir 一致 = 1，否则 0 | 0.10 |
- **用法**：score ≥70 强趋势（优中选优门槛）、40–70 可做、<40 放弃；跨品种按 score 排序分配监控优先级
- **状态**：🟡 定义 v1 定稿待评审；研究级代码已实现（无多周期输入时该项退化）；**实证检验完成**（2026-10-12，assets/MLIB/trend_score_check.py → trend_score_check.md）：pooled rank IC +0.028@20/+0.036@40（弱正）；**用法阈值方向正确**——<40 桶 +0.052% / 40-70 桶 +0.105% / ≥70 桶 +0.363%（n=45 小样本），D10 十分位 +0.289% 显著。**定位确认：适合做跨品种排序/优先级（其设计用途），绝对方向预测力弱（勿当独立信号用）**
- **消费方**：S-004 优中选优、阶段标签、RS001 因子族一

### M-LV-003 关键位状态机（Level State Machine）
- **定义 v1**（源自 RS010 统一模型）：每个关键位维护状态字段，事件驱动迁移：

- **消费方**：S-001 全部、S-004 任务单位状态标签、RS010
