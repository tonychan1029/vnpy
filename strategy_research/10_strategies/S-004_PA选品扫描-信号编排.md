# 策略文档：PA 选品扫描-信号编排（S-004）

> 定位：选品扫描策略（大周期）的核心产出不止是"选中品种"，而是
> **该品种在当前市场阶段下应监控/通知的 PA 信号列表**。择时策略（小周期）
> 只执行通知，不判断市场阶段——阶段判定是选品层的专属职责（它有大小周期配合的视角）。

## 1. 策略概要
- **一句话**：大周期扫描判定市场阶段与结构，按品种输出"择时监控任务单"：监控周期 + 具体信号（或信号组合）列表 + 有效期 + 关键位。
- **市场/品种**：期货全池扫描
- **周期**：选品级 60m/日线；输出约束择时层（1m/5m 执行）
- **类别**：选品编排 / 大小周期配合
- **当前状态**：researching

## 3. 策略逻辑
### 3.1 核心假设
1. 市场阶段（趋势/区间/反转/突破）决定**哪类入场信号有效**：同一种 K 线形态在趋势段和区间段的期望值完全不同。
2. 阶段判定需要大周期背景（60m/日线结构），择时层（1m/5m）视野内不可见。
3. 因此"信号武装列表"必须在选品层确定，择时层按单执行，避免小周期自作阶段判断。

### 3.2 输入输出契约（本轮核心产出）

**选品扫描的输出（择时监控任务单）——按品种逐条：**

| 字段 | 说明 | 现状 |
|------|------|------|
| symbol | 品种 | ✅ 已有 |
| selection_timeframe | 选品周期 | ✅ 已有 |
| exec_timeframe | 择时执行周期 | ✅ 已有 |
| context_tag | 市场阶段（trend_strong/trend_channel/range/breakout/reversal） | ✅ 已有 |
| **armed_signals** | **该品种当前应武装的信号 ID 列表（可含方向限定）** | ⚠️ 仅有粗粒度 REASON_DEFAULT_SIGNALS |
| **per_direction** | 每个信号的多/空方向许可 | ⚠️ 现为任务级 direction，未到信号级 |
| key_levels | 关键位（prior_high/low、range_top/bottom、gap_edge） | ✅ 已有 |
| valid_until / expiry | 任务单有效期（阶段未变则顺延） | ⚠️ 有 default_valid_bars，语义未绑定阶段 |
| stage_evidence | 阶段判定依据（供审计与复盘） | ❌ 缺失 |

**择时策略的输入** = 上述任务单；**输出** = 触发通知（模板见 §3.5）。

### 3.5 择时通知模板（v0，2026-10-12 用户确认）

择时层按任务单监控，在信号武装/状态变化/触发时通知用户，通知必须回答三个问题：
**当前在择时什么信号、要等什么信号入场、挂什么单入场。**

**通知类型 A：任务单生效（选品层下发/阶段切换）**
```
【武装】RB0 · 趋势阶段(trend_strong) · 有效至 xx 根K线内
等待信号：EMA20回踩做多（限价单）、结构位回踩做多（突破单）、高2做多（突破单）
关键位：前高 3850 / 前低 3762 / EMA20 3801
```

**通知类型 B：信号待触发（state=armed）**
```
【待触发】RB0 · EMA20回踩 · 做多
入场建议：限价单 @ 3801（EMA20−2tick buffer）
止损参考：3782（最近摆动低点 −0.25×ATR）
失效条件：60m 收盘跌破 3762（前低）
单型依据：回踩类信号→限价低挂等回落；突破类信号→突破单追触发
```

**通知类型 C：触发成交确认**
```
【触发】RB0 · 高2做多 · 突破单已触发
成交参考：3834（触发价+1tick 口径）
止损：3815（L2 摆动低点）；失效：收盘跌破 3815
形态依据：M-PT-003 高2（回调序数=2）
```

**通知类型 D：过期/失效/撤单**
```
【失效】RB0 · EMA20回踩 · 未触发过期（3根未触及）
原因：阶段切换 range→trend_strong，任务单已换发新信号列表
```

**order_type 判定规则（v0，源自现网 AlertDraft.order_type）：**
<!-- MTG005 遗留已落实：通知须标注"来源形态"，示例见类型 C 补充行 -->

| 信号 | 单型 | 逻辑 |
|------|------|------|
| ema_pullback | 限价单（低挂） | 等价格回落到 EMA 触及，顺势低吸/高抛 |
| structure_pullback / h2_l2 / breakout / second_breakout / range_edge / double_top_bottom / wedge | 突破单 | 确认方向后再进，宁错过不逆势 |
| fake_breakout | 突破单（反向） | 反手逻辑，突破原失效位才进 |

**来源形态标注规则（MTG005 决议落实）**：所有 C 类触发通知须附一行
`形态依据：<M-ID> <形态名>`（如 `形态依据：M-PT-005 W底(严格版)` 或
`形态依据：M-PT-002 双底(宽松版)`），使用户能区分同一信号的严格/宽松来源。

### 3.3 阶段 → 信号矩阵（v0，源自现有 REASON_DEFAULT_SIGNALS 与 detector 的 context 过滤）

| 市场阶段（context_tag） | 武装信号 |
|--------------------------|----------|
| breakout（突破中） | breakout、fake_breakout、second_breakout |
| trend_strong / trend_channel（趋势） | ema_pullback、structure_pullback、h2_l2 |
| range（区间） | range_edge、fake_breakout |
| reversal（反转） | double_top_bottom、wedge |

### 3.4 待补形态（用户点名，现 detector 集暂缺）
- **H1/L1 通知**（Al Brooks 体系：趋势中首次回调的高/低点一推）——趋势阶段的高频入场信号，现 h2_l2 只覆盖二次回调
- **W 形态通知**（W 底 / M 顶，双底双底的近亲但结构判据不同：W 强调中间颈线回抽行为）——现 double_top_bottom 只做摆动点聚类，无 W 结构判据
- 处置：列入本轮研究范围，先定义结构判据再决定是否新增 detector（移交工程侧实现）

## 4. 研究记录
- **长期量化纲领**：见 [RS001 选品三因子框架](../20_research/RS001_选品三因子框架.md)——趋势强度（优中选优）、回调衰竭（动能/量能背离，价格位置仅辅助）、失败捕捉（反向信号源）。择时信号保持纯 PA 不变；选品层按此框架做因子化补充与精简。
- **architect 原则（用户确认）**：择时策略信号基本/原则上按 PA 量化设计，未来一段时间不变；选品策略可基于大部分 PA 模型设计，亦可补充和精简。
### 4.1 与现网实现的差距清单
1. `REASON_DEFAULT_SIGNALS` 是静态映射；本策略要求**动态**：阶段迁移（如 range→breakout）时任务单信号列表随之切换。
2. 方向许可目前是任务级（direction=long/short/both），需下沉到信号级（如趋势阶段允许 ema_pullback 做多、但反弹做空类信号全禁）。
3. 阶段切换的过渡规则未定义：旧信号是立即撤单还是自然过期？（QA/RISK 关注点）
4. 信号组合：是否允许同品种同时武装趋势类+突破类？（如 trend_channel 下 breakout 仍有效）——需绩效数据支撑，待基线回测产出后决策。

### 4.2 大小周期职责边界（用户核心论点，团队共识）
- 阶段判定、信号编排、关键位维护 = **选品层**（60m/日线，有结构视角）
- 触发检测、通知推送、执行 = **择时层**（小周期，无阶段视角，只看任务单）
- 择时层发现任务单与盘面明显矛盾时的处理：仅上报，不自行改单（RISK 要求）

## 6. 参数与优化
待研究：任务单有效期（default_valid_bars 与阶段持续性的匹配）、阶段切换灵敏度（context_tag 判定参数）
- **【RS012-4a】armed 状态迟滞**：真值阶段中位持续仅 ~1 个交易日（20 根前瞻窗口下高频闪烁），armed/解除切换须加迟滞（连续 2~3 次判定一致才翻转），否则武装状态抖动 → 通知噪声。参数待判定标签侧数据确认（RS012 §4a）

## 7. 风险档案
- 阶段误判 → 整张任务单信号列表系统性错配（比单信号误判伤害大）
- 任务单过期与撤单规则不清 → 择时层执行过期信号
- 信号列表过宽 → 通知泛滥、择时层配额（quota）被低质量信号占满

## 8. 组合与状态跟踪
- 本策略是 S-001/002/003 的**上游编排层**，不直接产生交易信号
