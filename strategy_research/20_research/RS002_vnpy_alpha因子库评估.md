# 研究报告 RS002：vnpy alpha 因子库评估

## 1. 库的全貌（代码勘察结论）

`vnpy/alpha` 是一套完整的 Alpha 研究框架，五个组件：

| 组件 | 内容 | 对本项目的可用性 |
|------|------|------------------|
| `dataset/` 因子引擎 | **AlphaDataset**（polars 向量化+多进程）、表达式因子计算、算子库（`ts_function` 20+ 时序算子 / `cs_function` 截面算子 / `ta_function` TA-Lib / `math_function`） | ✅ **高价值，直接可用** |
| `dataset/datasets/` 现成因子集 | **Alpha101**（世界知价因子）、**Alpha158**（微软 qlib 同源） | 🟡 结构可借鉴，公式多为股票截面口径，期货时序场景需改写 |
| `model/` 机器学习 | Lasso / LightGBM / MLP 三种模型模板 | 🟡 二期可用（因子→模型组合预测） |
| `strategy/` 组合回测 | 权益组合回测（等权/多因子选股口径） | 🔴 与期货 PA 择时不匹配，不用 |
| `lab.py` 研究实验室 | 数据加载、实验流程封装 | 🟡 参考其工作流 |

配套：`examples/alpha_research/` 有 4 个完整研究 notebook（alpha101、lasso、lgb、mlp 工作流）。

## 2. 关键评估：三处"口径错配"与解法

1. **截面 vs 时序**：alpha 库为**股票截面**设计（同一时刻跨品种排序，quantile 分层）；我们的 PA 择时是**单品种时序**信号。解法：只用其**时序算子**（`ts_delay/ts_rank/ts_corr/ts_cov/ts_std` 等）和表达式引擎，跳过截面算子；分层评价改用我们自己的"信号胜率提升度"口径。
2. **股票字段 vs 期货字段**：Alpha101/158 公式假设股票量价字段；期货可用子集为 OHLCV + 换手代理量。解法：只移植公式结构，逐条改写口径（如剔除涨停/停牌假设）。
3. **评价体系**：库内置 **alphalens**（IC/IR/分层收益 tear sheet）——这是**现成的因子验证工具**，正好补 RS001 路线图"历史验证"一环的缺口，不必自研评价指标。

## 3. 用户判断的确认与体系化

用户的判断完全正确，且可以更精确地表述为**两级武器库**：

```
第一级：框架因子库（vnpy/alpha）
  └─ 通用算子（ts/cs/TA）+ 现成因子集 + 验证工具（alphalens）+ 模型模板
  └─ 特点：经社区验证、工程成熟、但口径偏股票截面

第二级：自有方法库（strategy_research/30_method_library, MLIB）
  └─ PA 特有判据（衰竭/背离/失败/摆动结构/阶段判定）
  └─ 特点：领域专属、我们的差异化竞争力所在
  └─ 定位：本质上是"用户自己的因子库"，用第一级的算子和验证工具来生产、检验
```

**关系**：MLIB 的每个方法（M-XX）在实现时**应优先用 alpha 库算子表达**（如 M-TR-002 trend_score 用 `ts_std/ts_corr` 组合；M-DV-001 量比用 `ts_delay/ts_mean`），算子不够再自定义——这保证了方法实现的工程质量与向量化性能。

## 4. 接入方式（移交工程侧的要点草案）

1. **因子计算管道**：研究侧因子验证统一走 `AlphaDataset.add_feature(表达式)` + `prepare_data()`，期货 60m 数据装配成 polars DataFrame（datetime/vt_symbol/OHLCV）即可接入；
2. **验证管道**：因子评价用 `show_feature_performance`（内置 alphalens）做初筛（IC/分层），再用我们的信号胜率口径做终筛（贴合择时场景）；
3. **依赖确认**：库依赖 polars/alphalens/scipy——`.venv` 中 polars 已存在，alphalens 需确认安装（移交单事项）；
4. **边界**：不使用 `alpha/strategy` 组合回测（口径不符），组合层评估仍按 MTG002 决策走。

## 5. 对研究路线的影响

- RS001 验证环节的工具缺口**已补齐**（alphalens + 表达式引擎），因子验证从"待建管道"变为"有现成管道"
- MLIB 增加"实现载体"字段：每方法标注 alpha 算子表达式或自定义实现（登记册维护规则第 5 条，见下）
- Alpha101/158 作为"公式素材库"：其中量价类公式可改造为我们的衰竭/背离因子的对照基准（新因子必须跑赢随机对照才有存在价值）
