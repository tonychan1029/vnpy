# 研究稿 RS004：H1/L1 与 W/M 形态结构判据

> 目的：补齐 MLIB 两个 🔴 未实现方法（M-PT-004、M-PT-005）的定义草案，
> 参考 TradingView 社区同类实现的公开判据先验（RS003 管道，候选卡 CAND-002/003）。
> **状态：判据草案，验证通过前不得进入策略实现。**

## 1. M-PT-004 H1/L1（趋势中首次回调一推）

### 1.1 行为逻辑（经济学解释）
趋势确立后的第一次逆向摆动，是趋势单获利了结与新增反向单的集中区；
首次回调被趋势方向吸收（形成 H1/L1）后顺势入场，对手盘是迟到的反趋势交易者。
这是 Al Brooks 体系中趋势段出现频率最高的入场结构。

### 1.2 判据定义（60m 选品级，可量化草案）

前置条件：
- context_tag ∈ {trend_strong, trend_channel}（复用 M-TR-003）
- EMA 斜率同向（复用 M-TR-001）

结构判据（多头 H1 为例）：
1. 最近的已确认摆动高点 H0 之后出现第一次向下摆动：出现已确认低点 L1（M-PT-001）
2. L1 为"首次回调"：L1 之前最近 `h1_lookback`(默认 20) 根内**无其他已确认低点**（区别于 h2_l2 的"第二次"）
3. 回调质量：L1 未跌破前一低点（结构保持），且 L1 ≥ EMA − `h1_ema_tol`(0.5)×ATR（浅回调优先；深度回调改由衰竭判据 M-EX-001 管理，不属本方法）
4. 恢复确认：L1 之后出现一根收盘 > L1 后首个中间高点 H_mid 的K线

触发与风控：
- 触发：确认K高点 + buffer 突破单（与 h2_l2 同构）
- 止损：L1 − 0.25×ATR；失效：收盘跌破 L1
- 新参数：`h1_lookback`=20、`h1_ema_tol`=0.5（登记 MLIB，待验证）

### 1.3 与 h2_l2 的关系
同一族不同序数：H1=第一次回调，H2=第二次。工程上可统一为"回调序数参数化"的单一 detector（n=1,2），判据共享，仅 `h1_lookback` 与结构历史要求不同——**移交建议：合并实现，减少重复**。

### 1.4 验证要点
- 与 h2_l2 信号的样本重叠度（预期 H1 信号更多、单信号质量略低）
- 分趋势强度档（trend_strong vs trend_channel）的胜率差异

## 2. M-PT-005 W 底 / M 顶

### 1.1 行为逻辑
W 底 = 空方两次推力在同名低位衰竭（第二次推力创新低或近似同低但动能不足），
中间反弹高点构成颈线；颈线突破确认双推衰竭完成。与 M-PT-002（双顶底聚类）的区别：
**双顶底只看两个摆动点等价；W/M 额外要求中间反弹（颈线回抽）的完整结构**，
即"两推+颈线"三要素，形态语义更完整、更严格。

### 2.2 判据定义（W 底为例）

结构判据：
1. 最近两个已确认低点 L1、L2（M-PT-001），间隔 5 ~ `wm_max_sep_bars`(默认 30) 根
2. 底部等价：|L2 − L1| ≤ `wm_tol_atr`(0.5)×ATR（比双顶底的 0.3 宽——W 允许 L2 略低于 L1 的扫损结构，即" wash & rinse"）
3. **颈线要素（与双顶底的关键区别）**：L1、L2 之间存在已确认高点 N（颈线），且中间反弹幅度 ≥ `wm_neck_min_atr`(1.0)×ATR
4. 第二推衰竭证据（任一，呼应 RS001 ②）：
   - L2 处出现 M-KB-001 针形或 M-KB-002 吞没
   - 量能背离 M-DV-002（实现后启用）
5. 触发：收盘突破颈线 N ± buffer（突破单）；止损：L2 − 0.25×ATR；失效：收盘回落至颈线下方

M 顶完全对称。

### 2.3 与 M-PT-002 的关系（重要）
判据包含双顶底（条件 1–2 是其超集），但更严格。**重叠处理**：同信号同向时按"更严格者优先"——W/M 触发时抑制双顶底重复通知（S-004 编排层处理，消费方已标注）。

### 2.4 验证要点
- 严格版（W/M）vs 宽松版（双顶底）的信号数与胜率对比，量化"严格性溢价"
- 扫损结构（L2<L1）子样本单独统计——这是 W 形态理论上的核心优势场景
